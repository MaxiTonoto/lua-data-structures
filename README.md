# lua-data-structures

Library containing data structures implemented 100% in the Lua programming language.  
The project follows Python's naming conventions:  
- **snake_case**: functions, variables, modules.  
- **SCREAMING_SNAKE_CASE**: constants.  
- **PascalCase**: classes.
